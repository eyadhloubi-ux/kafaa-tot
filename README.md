# TOT — مقترح برنامج تدريب المدربين

عرض تفاعلي (ملف واحد) لمقترح برنامج TOT المقدَّم لوزارة الداخلية.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | العرض كاملاً (كل الصور والتصميم مضمّنة داخله) |
| `favicon.png` | أيقونة الصفحة في المتصفح |
| `render.yaml` | إعداد النشر على Render |
| `.nojekyll` | لازم لـ GitHub Pages حتى يُنشر الموقع كما هو |

## الرفع على GitHub
1. أنشئ مستودعاً جديداً (مثلاً `tot-proposal`).
2. ارفع كل الملفات الموجودة في هذا المجلد إلى جذر المستودع (Add file ← Upload files)، بما فيها `.nojekyll`.

## النشر على GitHub Pages
Settings ← Pages ← Source: **Deploy from a branch** ← Branch: `main` / `(root)` ← Save.
بعد دقيقة يصبح الرابط: `https://اسم-الحساب.github.io/tot-proposal/`

## النشر على Render (بديل)
New ← Blueprint ← اختر المستودع؛ يقرأ Render ملف `render.yaml` وينشر الموقع تلقائياً.

## التنقّل في العرض
- الأسهم ← → أو النقر، أو الأزرار أسفل الشاشة.
- في شريحة «المحاور الأساسية» اضغط على رقم أي محور لعرض محاوره الفرعية.
- زر `F` للعرض بملء الشاشة.

> الخطوط تُحمَّل من Google Fonts، فيحتاج العرض اتصالاً بالإنترنت لتظهر بخطها الأصلي.
