# كفاءة TOT

عرض تفاعلي من 10 شرائح لبرنامج «كفاءة TOT» لبناء منظومة تدريب داخلية في وزارة الداخلية بالتعاون مع DOMAINS:
الفكرة، مسار البرنامج بمراحله الأربع، ثم شريحة لكل مرحلة (إعداد المدربين TOT، تصميم الحقائب وحقيبة القيادات، توزيع الأدوار، التطبيق والتقييم)، المخرجات، والختام.

## محتوى الحزمة

```
index.html        الصفحة الرئيسية
css/style.css     التصميم
css/fonts.css     تعريف خط Alexandria
js/main.js        التنقل والحركة
fonts/            ملفات الخط (مضمّنة، لا تحتاج اتصالاً بالإنترنت)
render.yaml       إعداد النشر على Render
.nojekyll         لـ GitHub Pages
```

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub وارفع إليه كل محتويات هذا المجلد كما هي.
2. من إعدادات المستودع: **Settings ← Pages**.
3. في **Source** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**.
4. بعد دقيقة تقريباً يظهر رابط العرض في نفس الصفحة.

ويمكن أيضاً فتح `index.html` مباشرة من الجهاز بدون إنترنت.

## النشر على Render

1. ارفع الملفات إلى مستودع على GitHub.
2. من لوحة Render اختر **New ← Blueprint**، واربط المستودع.
3. سيقرأ Render ملف `render.yaml` وينشئ موقعاً باسم `kafaa-tot`. اضغط **Apply**.

لا يحتاج الموقع أي خطوة بناء، وكل تحديث ترفعه إلى المستودع يُنشر تلقائياً.

## طريقة العرض

- العرض يتنقل **شريحة شريحة** على كل الأجهزة.
- **اللابتوب:** عجلة الماوس أو الأسهم أو النقر على مساحة فارغة.
- **الموبايل والتابلت:** السحب للأعلى أو لليمين للتقدم.
- **شريحة مسار البرنامج:** اضغط على أي مرحلة للانتقال مباشرة إلى شريحتها.
- زر **القائمة** للانتقال المباشر لأي شريحة، وزر **ملء الشاشة** للعرض أمام الجمهور.
